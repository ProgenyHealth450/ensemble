$ az boards --help

Group
    az boards : Manage Azure Boards.

Subgroups:
    area        : Manage area paths.
    iteration   : Manage iteration paths.
    work-item   : Manage work items.

Commands:
    query       : Query Azure Boards using a work item query (WIQL).

Examples:
    Query work items using WIQL.
        az boards query --wiql "SELECT [System.Id] FROM WorkItems"

$ az boards work-item --help

Group
    az boards work-item : Manage work items.

Subgroups:
    relation    : Manage work item relations.

Commands:
    create      : Create a work item.
    delete      : Delete a work item.
    show        : Show details for a work item.
    update      : Update a work item.

Examples:
    Create a work item.
        az boards work-item create --title "Sample task" --type Task --description "A sample"

    Show details for a work item.
        az boards work-item show --id 1234 --expand relations

    Update a work item.
        az boards work-item update --id 1234 --state Active

    Update a work item's discussion.
        az boards work-item update --id 1234 --discussion "A new comment"

    Close a work item.
        az boards work-item update --id 1234 --state Closed

$ az boards work-item relation --help

Group
    az boards work-item relation : Manage work item relations.

Commands:
    add         : Add a link to a different work item.
    list-type   : List the types of links available.
    remove      : Remove a link to a different work item.
    show        : Show details for a list of work item relation types.

Examples:
    Add a link to a different work item.
        az boards work-item relation add --id 1234 --relation-type Predecessor --target-id 1235

$ az boards query --help

Command
    az boards query : Query Azure Boards using a work item query (WIQL).

Arguments
    --id                  : One or more IDs of a saved query.
    --org --organization  : Azure DevOps organization URL.
    --path                : Path of a saved query.
    --project -p          : Name or ID of the project.
    --team                : Name or ID of the team.
    --wiql                : Work item query language (WIQL) query string.

Examples:
    Query work items using WIQL.
        az boards query --wiql "SELECT [System.Id] FROM WorkItems"

$ az devops configure --help

Command
    az devops configure : Manage the user settings for the Azure DevOps CLI, such as the
    default organization and project.

Arguments
    --defaults            : Space-separated list of 'key=value' pairs to configure default
                             values, for example 'organization=https://dev.azure.com/org
                             project=myproject'.
    --list                : List configuration values.
    --use-git-aliases {false, true} : Enable or disable setting up 'git' aliases for
                             'pull request'.

Examples:
    Set the default organization and project.
        az devops configure --defaults organization=https://dev.azure.com/myorg project=myproject

    List current configuration values.
        az devops configure --list
